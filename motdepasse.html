Tester un mot de passe

Saisis un mot de passe pour voir l'estimation.

L'estimation est approximative. Ne saisis jamais ici un mot de passe que tu utilises vraiment : même si rien n'est envoyé, mieux vaut tester un mot de passe équivalent.

Tout se passe dans ton navigateur : rien n'est envoyé ni enregistré. Le temps de cassage est une estimation : il dépend surtout de l'algorithme qui protège le mot de passe (bcrypt ou Argon2 ralentissent énormément l'attaquant par rapport à MD5). Les mots de passe sont tirés avec le générateur aléatoire sécurisé du navigateur (crypto.getRandomValues).
